# 本地验证记录（2026-11-11，Asia/Shanghai）

本文件记录本地实际执行结果，不是正式准入、性能榜或 Agent 评分。

## 固定镜像与公开题包

Dockerfile 从已锁定基础镜像和仓库源码构建，随包 NumPy wheel 的 SHA256 校验通过。基础镜像可用之后，以 `docker build --network=none -t minivectordb:local .` 成功完成离线构建。

最终测试镜像 ID：`sha256:08b882bbbb121b6cdcc4a54741e319b7d0da5ad1c57b0e733d267fa97dc6a954`。代码提交 SHA 由包含本记录的 commit 绑定；这里不预填尚未生成的 SHA。

使用未修改的 `protocol_check/run.py`，对固定镜像执行完整公开题包：`passed: true`，**20/20 个样例、95 条 SQL**。容器设置来自题包：禁网、只读根文件系统、2 CPU、2 GiB、无 swap、128 PID；每个用例独立卷，重启复用卷。原始结果在本地 `protocol-results/docker-final-002/result.json`；关键内容也嵌入 `agent/conversation.json`，学习材料不依赖外部文件读取。

## 扩展正确性与恢复

Windows 与 Linux/WSL 均执行过扩展测试。最终 Linux 版本运行 `python -m unittest discover -s tests -v`，**13 tests，OK**，耗时 44.999 秒。主要检查：

- 超过 JavaScript 安全整数范围及 BIGINT 两端边界；中文、补充平面字符、Unicode 长度和码点排序。
- float32 舍入、维度错误、非数值、NaN/Infinity 和溢出拒绝。
- 多行失败原子性、事务失败后继续提交、更新/删除/再插入、索引和记录视图一致。
- 350 步固定随机操作与独立字典参考状态对照，定期比对过滤 TopK。
- 一个多操作提交帧的全部 **140 个字节前缀**：每种截断只能得到完整旧状态或完整新状态。
- 2,400 个有符号主键跨哈希扩容后重启读写；低预算下触发 32 路磁盘归并排序与缓存回退。
- 800 条、8 维向量，创建索引后以 20 个独立查询对照暴力距离真值；包含过滤和多块索引。
- 强制关闭进程后的已提交保留与未提交丢弃；请求 ID 类型及错误后继续处理。

## 数据大于内存预算

最终固定镜像在 **128 MiB**、无 swap、禁网、只读根文件系统下写入 6,000 条记录，每条文本 32,768 字节；文本总量 **196,608,000 字节**，最终提交日志 196,857,728 字节，大于内存上限 134,217,728 字节。

`scripts/stress_docker.py` 完成 137 条 SQL 操作，检查全部主键、条件查询、TopK、SIGKILL 后未提交更新/删除回滚、已提交更新保留，以及 3 次启动期间终止后的再次恢复。`passed: true`，写入阶段约 52.747 秒，总耗时约 72.256 秒。

最终重启容器的 `memory.peak=70361088`，`memory.max=134217728`，`oom=0`、`oom_kill=0`。这些资源数字仅覆盖最后一次容器生命周期，不是整个多容器测试的统一峰值。测试通过说明此负载可以在限额下完成；不能将最终重启的峰值冒充装载全过程峰值。定时启动强杀也不能证明每次中断发生在恢复的某条特定指令。

本地原始结果：`local-results/stress-final-128m/result.json`，并嵌入学习记录。Docker Desktop 的本地 `io.stat` 不能直接当作正式专用设备计分指标。

## 性能烟测

`scripts/benchmark.py` 使用固定种子，10,000 条、128 维、100 条一批、1,000 次 Top10 查询，一半带普通列过滤。数据生成不计入写入时间，查询预热一次。前 10 次查询与 Python 独立暴力距离计算核对 ID 和距离，核对部分 Recall=1.0。

| 本地环境与路径 | 写入秒 | 查询秒 | 打开/准备秒 |
| --- | ---: | ---: | ---: |
| Windows，无向量索引 | 9.609 | 10.615 | 0.148 |
| Linux/WSL，有向量索引 | 9.491 | 6.623 | 0.623 |
| Linux/WSL，无向量索引 | 11.654 | 9.253 | 0.153 |

这些是单轮进程内烟测，部分运行期间同时有其他本地检查；不同操作系统和负载不能用于严谨的速度比结论。Linux 的 RSS 包括基准数据生成器；不是容器整体 cgroup 峰值。没有测量正式三轮端到端 T、专用设备 B、容器全过程 M，也没有固定基线，不能计算综合 E 或赛事分数。未独立核对的 990 次烟测查询不应声称全部通过独立真值验证。

## 开发中的错误与修正

第一次构建误用了禁网配置但尚未捆绑依赖，pip 无法解析域名；随后联网下载在约 5.5 MB 处中断，被官方哈希校验拒绝。保留原有正确哈希，改用与官方 SHA256 一致的完整镜像源 wheel 随包安装，成功离线构建。

WSL 初次 Docker 测试因未启用 distro daemon 集成而失败，增加独立 CLI 适配器转发给 Docker Desktop，未改题包驱动。一次固定镜像测试误把 build 输出的 config 摘要当作 Docker Desktop 镜像 ID，得到 `No such image`；通过 `docker image inspect` 获取实际 ID 后，完整公开题包重测通过。失败报告保留在本地，没有改写成通过。
