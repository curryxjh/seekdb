# Agent Prompt 材料与本次修订

唯一待评学习材料为 `agent/conversation.json`。文件名使用题包要求的 conversation，不使用用户消息里可能笔误的 conversion。材料随数据库源码、Dockerfile 一同提交，正式评测应锁定包含它们的同一个 commit。

## 本次探索结论

题目第 4.4 节明确允许自选内部业务字段，要求 UTF-8、顶层对象、不超过 128 KiB、无重复键、无 NaN/Infinity、无密钥。指定上游分支仍为 `f4d4e26653af823a7601668802f80e374ad6643c`，没有新的公开评测 JSON schema。有限公开检索中未找到额外的权威输入格式或可运行评测器；不能把检索未找到理解为不存在私有平台配置。

上一交付 `7635966bd677ed960778e942782ef3aad8407476` 的学习文件远端可下载（HTTP 200），50,705 字节，SHA256 为 `8ebf73f27b5df787b3b48788896d366a36a992b5a59e5caa6dd89c18bfa1e43d`，与 Git 对象一致。这只证明指定版本和路径可获取，不证明平台实际使用了该路径或已完成评审。

平台反馈将无效、待复核、超出 0–100 和缺少材料摘要合并成一个提示；没有原始报告，不能确定触发条件。题目说原始分不封顶，与该提示存在口径差异。目前保留原始提示，未自行填分、截断或换算。页面“通过率：0%”也不作为某个提交的原始分依据。

## 已做的改进

- 将重复题目全文压缩成标明出处的必要原文摘录，保留实现约束及学习证据规则。
- 增加可读 `summary`，保留学生真实任务要求、失败反馈、修订请求，以及 Agent 的诊断与实际工具结果。
- 增加可定位的 `evidence_index`，每个引用指向文件内字符串字段，引用原文不超过 240 字符。
- 明确区分学生发言、Agent 计划/判断及工具结果；不把 Agent 的测试、修复或反思写成学生贡献。
- 新增本地结构校验器及独立文件 SHA256 报告。摘要字段和证据索引均是自选组织方式，不宣称平台强制要求；文件 SHA256 也不等于平台已经生成材料摘要。
